# SLR of XR in Basic Education

This repository contains the extraction, coding, methodological appraisal,
and synthesis data for the extended systematic literature review:

**Extended Reality in Basic Education: A Systematic Literature Review of
Context, Reported Effects, and Methodological Quality.**

## Relationship to the previous mapping

The previously published systematic mapping reported 45 studies. During
preparation of the extended review, one study was identified as retracted
by the publisher and was excluded from the current evidence synthesis.
The corrected evidence corpus contains 44 studies.

## Study subsets

- RQ1–RQ4 corrected reanalysis: 44 studies.
- RQ5 contextual analysis: 44 studies.
- RQ6 core outcome synthesis: 21 basic-education studies.
- RQ6 sensitivity analysis: 11 studies.
- RQ7 methodological appraisal: 32 empirical studies.

## Repository contents

The main workbook contains all extraction and synthesis information,
including the codebook, evidence map, RQ5 context data, RQ6 outcome
coding, RQ7 MMAT appraisal, and supporting analysis sheets.

## Workbook

`XR_SLR_Extraction_and_Synthesis.xlsx`

## Missing-data codes

- `NR`: not reported.
- `NA`: not applicable.
- `UNC`: unclear.
- `P`: partially reported.

## Data use

The workbook supports the tables, figures, and analyses reported in the
associated manuscript. Users should cite the version-specific DOI
assigned through Zenodo.
